名稱：星塵物語 (Arcturus: The Curse and Loss of Divinity，繁中／簡中版)
簡介：韓國Sonnori與Gravity 2000年共同出品的角色扮演遊戲，由Wizard代理發行，以3D畫
      面呈現，採團隊回合制方式戰鬥。2003年由上海依星簡中化並代理發行，但中文化的
      品質很糟，且問題百出，為眾多玩家所詬病。台灣雖由松崗代理進口，但並未繁中化
      [待補]。

操作：

滑鼠左鍵/方向鍵 = 移動
滑鼠左鍵/Alt = 動作（如交談）
滑鼠右鍵/QW = 旋轉視角
AZ = 縮放視角
Ctrl = 確定／跳躍
滑鼠右鍵按自己/F2 = 人物欄
F3/F4 = 地點方向指示
F5 = 顯示俯瞰圖
F9 = 截圖
Esc = 離開遊戲
